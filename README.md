# TrueFit Android Application

TrueFit is a seamless, fully responsive Android application optimized for client intake and assessment. Originally starting as a web-based prototype, it has been packaged into a native Android application using Vite and Capacitor. 

## Tech Stack
- **Frontend**: Vanilla HTML/CSS/JS (Vite)
- **Native Wrapper**: Capacitor
- **Platform**: Android

## Prerequisites
- Node.js (v18+)
- Android Studio (for building and deploying to a device/emulator)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Mode
To work on the web UI and see live changes in your browser:
```bash
npm run dev
```

### 3. Build the Application
To compile your frontend assets for production:
```bash
npm run build
```

### 4. Sync to Android
After building your UI assets, sync the changes to your Android project:
```bash
npx cap sync android
```

### 5. Run on Android Device / Emulator
You can open the Android Studio project directly using the Capacitor CLI:
```bash
npx cap open android
```
From Android Studio, click the **Play** button to run the application on your connected Samsung Galaxy A53 or an Android Emulator.

## Project Structure
- `index.html`: The main application view, functioning as a responsive PWA.
- `package.json`: Contains project dependencies (Vite, Capacitor).
- `capacitor.config.json`: Core configuration settings for Capacitor.
- `android/`: The auto-generated Android Studio project containing your native application.
- `dist/`: The production output directory generated by Vite.
